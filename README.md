## Descripción

ESP Tool Pro es una herramienta de escritorio desarrollada en Python para facilitar la detección y administración de dispositivos ESP32 y ESP8266.

La aplicación proporciona una interfaz gráfica para detectar dispositivos, identificar el chip, borrar la memoria Flash y reiniciar el dispositivo.

## Características

- Detección automática de puertos COM
- Identificación automática del chip
- Soporte para ESP32
- Soporte para ESP32-S2
- Soporte para ESP32-S3
- Soporte para ESP32-C3
- Soporte para ESP32-C6
- Soporte para ESP32-H2
- Soporte para ESP8266
- Borrado de memoria Flash
- Reinicio del dispositivo
- Comunicación serial
- Interfaz gráfica profesional
- Integración con esptool

## Requisitos

- Python 3
- Una placa ESP compatible
- Cable USB de datos
- esptool
- pyserial
